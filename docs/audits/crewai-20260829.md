## 0. 摘要

本审计对开源项目 **CrewAI**（crewAIInc/crewAI，commit `da4daadba0e5049abc00fee8bc31b8b8019c60dd`，MIT 协议）执行"文档级"负责任架构安全审计：仅以公开文档（README + docs/edge/en/concepts 概念文档 11 份）为输入，构造结构化架构 JSON（`arch.json`）交由 hive-security 确定性规则引擎扫描，并对引擎输出逐条人工复核、对疑似产品级问题做克隆源码 grep 抽查。

最终结论：**hive-security 扫描裁决为 `pass`，0 条 finding（sarif/json 两格式退出码均为 0）**。修正前的首次扫描曾产出 1 条 `T-PATT-1`（循环依赖）finding，经复核为输入构造产物（编造了文档未描述的 `Knowledge→Agent` 依赖，违反审计契约"文档未说的不编造"），修正输入后消失，属误报而非目标产品缺陷。人工复核与源码抽查**未发现需要私下披露的产品级漏洞**；文档层面存在若干安全相关 Warning 与观察（不可信 JSON 项目执行本地代码、代码执行功能弃用、遥测数据边界等），均已按"文档级观察"记录，不构成产品缺陷结论。

**本审计不构成安全保证**：这是基于公开文档的静态设计审计，未做动态测试、依赖/供应链分析与运行时验证，检出率受内置威胁目录（中文关键词）与输入构造方式影响，详见第 5 节。

## 3. 误报分析

**误报数量：1 条（占唯一产出 finding 的 100%）**；最终扫描 0 finding。

**误报分类（1 类）——输入构造产物**：

- `T-PATT-1` 循环依赖：`Knowledge.depends_on=["Agent"]` 系我（审计输入构造者）编造的依赖，违反审计契约"depends_on 只写文档明确描述的依赖…文档未说的不编造"。文档证据链：agents.mdx L69 只写 Agent 的 `knowledge_sources` 属性（Agent→Knowledge），knowledge.mdx L10-11 只写"Knowledge … allows AI agents to access and utilize external information sources"（被动数据源），均无 Knowledge→Agent 反向依赖表述。删除该键后依赖图变为 DAG，重扫 `check_dependency_cycle: 0 findings`。**该误报不反映 CrewAI 产品缺陷**，而是"检出率受输入构造影响"的直接演示（见第 5 节）。

**为什么其余威胁关键词未命中（检出率局限，非误报）**：内置威胁目录 12 条的关键词几乎全部为中文（"认证/鉴权/身份/令牌"、"注入/校验"、"白名单/shell"、"审计/日志/溯源"、"密钥/脱敏/泄露"、"合规/隐私/GDPR"、"限流/配额/预算/超时"、"守卫/降级/护栏"、"幻觉/引用/编造"、"循环依赖/单点/risks" 等）。本审计按契约以**英文原文**填写 responsibility/interfaces，中文关键词无法命中（唯一英文词 "shell"、"gdpr"、"risks" 未出现在模块文本中），故 `check_missing_security_controls: 0 findings`。这是引擎语义限制（中文关键词目录对英文文档不敏感），不是"目标无风险"的证据。

## 5. 未覆盖范围声明

1. **非源码检查**：本审计以公开文档为输入构造架构 JSON，hive-security 只消费结构化 JSON、不解析源码；仅对疑似产品级问题做了有限 grep 抽查，未做代码级安全审计、未运行动态/模糊测试，**不构成安全保证**。
2. **不覆盖依赖/供应链/运行时**：未分析第三方依赖（crewai-tools、langchain、litellm、chromadb 等）、PyPI 供应链风险、运行时隔离（Docker/沙箱）的实际效果。
3. **内置威胁目录为中文关键词**：对英文文档检出有限（本次英文模块文本 0 命中），"0 finding / pass" 不等于目标无风险，只能说明在给定输入与目录下未命中规则。
4. **检出率受输入构造影响**：本次唯一 finding（T-PATT-1 循环依赖）即由输入构造违反契约所致并已修正；`risks` 字段为文档摘录而非目标官方风险清单（文档无正式 Risks 章节）。
5. **文档版本漂移**：所读文档为 `docs/edge/`（Edge 版），与发布版 `docs/v<X.Y.Z>/` 快照可能存在差异；审计日期 2026-08-29 之后的上游变更不在范围内。
6. **本报告不用于豁免任何后续安全测试**；生产部署前应执行完整的威胁建模、渗透测试与供应链评估。
