0230 秒演示

① hive-security：架构安全验证（CLI）

hive-security scan --input arch.json --format sarif --output report.sarif
# 退出码：0 = pass / pass_with_warnings；2 = fail（可阻断 CI）；3 = 执行错误

② hive-cost：成本预算与模型熔断（CostGate）

from hive_cost.budget import CostBudget
from hive_cost.gate import CostGate

gate = CostGate(budget=CostBudget(max_tokens=100_000, warn_ratio=0.8))
decision = gate.check_before_call("deepseek-chat", "编码")  # proceed / downgrade / block
gate.record_after_call("deepseek-chat", "编码", 1200, 300)  # 成本按定价表估算
gate.to_otel_events()       # OTel 兼容事件，JSONL 落盘（可被 Langfuse/LangSmith 消费）

03四个空白维度的组合（差异化卖点）

#维度卖点
①契约一等公民 + 防漂移工作包契约 = 机器可读的单一事实源：Pydantic PackageSpec → 公开 JSON Schema → contract-lint CLI → 漂移检查进 CI，实现「文档与实现零漂移」。
②契约级 HITL 验收回流验收不通过自动带反馈返工，≤3 轮后熔断；人工审批只在「架构方案 + 批次表」两个契约级关口介入，其余全程自动。
③架构安全验证内嵌审批关口审批前自动运行 hive-security 规则引擎（幻觉引用 / 循环依赖 / 缺失控制 / 反模式），fail 自动回流；SARIF 工件可直接进 CI 门禁。
④成本预算 + 模型熔断一等原语hive-cost：CostGate 预算检查 / 降级链 / 阻断，重试 / 熔断 / fallback，OTel 兼容 JSONL 导出；主流 agent SDK 均缺失该原语。

07安全与隐私

  • 本站零遥测：纯静态页面，无任何第三方统计 / 分析脚本，无 cookie；唯一外部资源是 shields.io 徽章图片（仅用于展示仓库状态，不收集访客数据）。
  • CLI 默认不执行命令：危险命令需 --allow-danger 显式放行，危险片段默认被拦截（如 rm -rf、路径逃逸），命令执行有超时保护。
  • 密钥只存本地：配置在本地 .env，不进入代码、不上传服务器；运行产物默认留在本地 runs/ 目录。
  • 检查范围声明：hive-security 为确定性规则引擎，只消费结构化架构 JSON，执行幻觉引用 / 循环依赖 / 缺失安全控制 / 架构反模式四项检查（12 条威胁目录映射 CWE + OWASP LLM Top 10 2025）；hive-cost 覆盖预算检查、降级链、熔断 / 重试 / fallback 与 OTel 兼容导出。
  • 未覆盖范围：不解析源码、不扫描依赖 / 供应链、不做动态渗透测试；不调用 LLM 语义验证通道；「pass」只表示在给定输入与规则版本下未命中规则，不构成「绝对安全」结论；成本为估算值（内置静态价格表）。

08FAQ

为什么叫「蜂群（hive）」？
一个「首脑」统筹多个专家智能体，像蜂群一样分工协作：首脑负责架构设计与契约分包，专家并行执行，首脑验收并集成。蜂群既是协作形态的比喻，也强调「群体智能优于单体」——契约与审批把分散的智能体拧成一支有序的队伍。
iOS 怎么安装？需要去 App Store 吗？
不需要。agent-hive 官网是一个 PWA：用 Safari 打开本站 → 点「分享」→「添加到主屏幕」，即可像原生 App 一样全屏运行。首次安装需联网，之后支持离线打开。
PyPI 什么时候上线？现在能装吗？
v0.2.0 即将发布：GitHub Releases 已提供 Windows / macOS / Linux / wheel 全平台资产，现在就能通过上方 wheel 直链 pip install。PyPI 发布正在同步推进，上线后 pip install agent-hive 即装即用。
它会执行我的命令、上传我的密钥吗？
不会。CLI 默认不执行任何命令，危险操作需 --allow-danger 显式放行；密钥只存本地 .env，不进入代码、不上传；本站也没有任何统计脚本。想审计？整个仓库开源，欢迎自查。
和 LangGraph 是什么关系？
agent-hive 构建在 LangGraph 之上：用 StateGraph 定义工作流，Send 实现专家并行 fan-out，interrupt 实现人工审批关口。在此之上，我们补齐了主流 agent SDK 普遍缺失的原语：契约驱动的验收回流、架构安全验证（hive-security）与成本预算 / 模型熔断（hive-cost）。
