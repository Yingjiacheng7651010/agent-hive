agent-hive 蜂群

契约驱动的多智能体编排框架：一个「首脑」定架构、分包派发、验收集成；契约是运行时一等公民，架构安全验证与成本预算内嵌为审批关口的一等原语，输出 SARIF / OTel JSONL 标准工件。

四个空白维度的组合（差异化卖点）

#维度卖点
①契约一等公民 + 防漂移工作包契约 = 机器可读单一事实源：Pydantic PackageSpec → 公开 JSON Schema → contract-lint CLI → 漂移检查进 CI
②契约级 HITL 验收回流验收不通过自动带反馈返工（≤3 轮后熔断）；人工审批只在「架构方案 + 批次表」两个契约级关口
③架构安全验证内嵌审批关口审批①前自动跑 hive-security 规则引擎（幻觉引用/循环依赖/缺失控制/反模式），fail 自动回流；SARIF 可进 CI
④成本预算 + 模型熔断一等原语hive-cost：CostGate 预算检查/降级链/阻断 + 重试/熔断/fallback；OTel 兼容 JSONL 导出；主流 agent SDK 全部缺失

30 秒演示

pip install hive-security
hive-security scan --input arch.json --format sarif --output report.sarif
# 退出码：0 = pass/pass_with_warnings；2 = fail（可阻断 CI）；3 = 执行错误

成本预算（100 任务 × 3-20 次调用，三档预算）完成率 100% → 64%（70% 预算）→ 52.2%（50% 预算）；任务成本均值 $0.0040 → $0.0026 → $0.0019；降级 0 → 95 → 85；block 0 → 37 → 47

复现：uv run python benchmarks/security/run.py 与 uv run python benchmarks/cost/run.py（详见仓库 benchmarks/README.md）。

安装

pip install hive-security hive-cost          # 独立组件（任何框架可消费）
uv sync                                        # 本仓库完整框架
uv run python -m agent_hive run --goal "..."   # 运行首脑

检查范围 / 未覆盖范围声明

  • 检查范围：hive-security 为确定性规则引擎，只消费结构化架构 JSON，执行幻觉引用/循环依赖/缺失安全控制/架构反模式四项检查（12 条威胁目录映射 CWE + OWASP LLM Top 10 2025）；hive-cost 覆盖预算检查、降级链、熔断/重试/fallback 与 OTel 兼容导出。
  • 未覆盖范围：不解析源码、不扫描依赖/供应链、不做动态渗透测试；不调用 LLM 语义验证通道；不做「绝对安全」结论——「pass」只表示在给定输入与规则版本下未命中规则；成本为估算值（内置静态价格表）。
  • 零遥测：本站为纯静态页面，无任何统计脚本；hive-security / hive-cost 默认零遥测。
